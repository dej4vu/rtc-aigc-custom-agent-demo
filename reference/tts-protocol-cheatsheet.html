SeedTTS 3.0 协议速查表

请求是一条句子的合成契约；响应是一行行 JSONL 事件；标签只进 TTS，不进眼睛。

请求契约

项值 / 规则
EndpointPOST /api/v3/text-to-speech/{voice_id}/streaming
认证头X-Api-Key；3.0 另有 X-Request-Id，不使用 X-Api-Resource-Id。
text保留官方内联标签的语音文本。
model_id默认 doubao-seed-tts-3.0。
enable_subtitle默认 true，请求字词级 alignment。
output_formatpcm / 24000，必须匹配 MMPG pcm24。
voice_settingsspeed、pitch、instructions。
session_id同一 turn 的多句共用，稳定语气。

JSONL 事件

event含义Agent 处理
ready流已建立。等待音频。
audioBase64 PCM。解码后按序回传 assistant.audio.delta。
alignment字词时间戳。交给 subt 自定义消息，供前端字幕联动。
final本句合成完成。标记本句 ended。
error错误 + request_id。终止本句，Trace 显示 tts_error。

双通道文本

  • TTS / 请求日志：保留 [happy] 等白名单标签。
  • 字幕 / LLM 历史：调用 stripInlineTags() 清洗标签。
  • 白名单：54 个情绪/语气标签 + 28 个副语言标签，共 82 个。
  • 非白名单：[备注]、[Note] 保留，不误删业务方括号。
  • 流式部分标签：句尾出现 [so、[ 时先隐藏，等 delta 补齐。

提示词规则

  • 只使用官方英文标签；不翻译、不自造、不用中文方括号。
  • 一次回复通常 1-2 个，最多 3 个。
  • 同一位置一个标签；禁止 [happy][soft] 连排。
  • 副语言标签插入后不再写重复拟声词。
  • 没有合适标签时宁可不加。

排障

  • HTTP 403：音色未授权；更换已开通 speaker。
  • 无声音：检查 speaker、JSONL error、24 kHz、最后包 done=true。
  • 标签出现在字幕：检查是否漏调用 stripInlineTags()。
  • 标签被朗读：确认标签在白名单且只控制 TTS，不要作为正文返回。
  • 时间戳缺失：检查 TTS_ENABLE_SUBTITLE 和 alignment 分发。
