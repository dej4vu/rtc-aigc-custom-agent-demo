端到端交付速查表

先静态，后外部；先自动化，后真实浏览器；先功能，后清理。

验收漏斗

  1. 静态健康：curl -s http://127.0.0.1:3101/health；期待 ok=true、issues=[]。
  2. 凭证与 Bot：yarn preflight；必要时 yarn preflight -- --handshake。
  3. 网关参数：yarn probe；真实创建一次 session.create。
  4. 行为基准：yarn test；当前通过基线是服务端 37 + 前端 16。
  5. 生产构建：yarn --cwd web build。
  6. 真实链路：yarn dev，浏览器允许麦克风，完成欢迎语和两轮对话。
  7. 清理：显式挂断后 activeCalls=0。

分层排障

连不上 3101
服务未启动、HOST/PORT、CORS、前端 proxy host。
preflight 失败
AK/SK、RTCFullAccess、账号、BOT_ID。
probe 失败
ASR ApiKey / ApiResourceId / StreamMode；不要包 Credential。
进房无字幕
麦克风权限、发布、client.ready、ASR 事件。
有字无声
TTS 403、speaker、pcm24、最后包 done、自动播放。
无法打断
asr.started、barge_in、client.interrupt、音频静音。
activeCalls 残留
/session/stop、gatewayClose、beforeunload sendBeacon。

安全交付底线

  • 密钥只进服务端环境；前端只拿一次性 RTC Token。
  • /health 只返回配置存在性和活动会话数，不返回值。
  • 日志默认不记完整转写；开启 LOG_TRANSCRIPTS 前先评估隐私。
  • 生产限制 CORS origin，不要依赖本地 localhost 放行。
