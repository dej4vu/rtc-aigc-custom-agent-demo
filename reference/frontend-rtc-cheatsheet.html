自定义消息方向

方向格式处理
浏览器 → 服务端cmsg TLV + 普通 JSONGateway 转为 user.message。
服务端 → 浏览器MMPG assistant.message.payload，常表现为 UTF-8 JSON 或 cmsg TLVRTC onRoomBinaryMessageReceived 接收。
状态conv + Stage Code更新听/想/说/打断/结束。
字幕subv + data[0]渲染用户和 Agent 文本。
Tracetrace + stage进入全链路 Trace 面板。
手动打断cmsg + client.interrupt服务端调用 cancelCurrent。

TLV 帧

0-3   magic，例如 cmsg / subv
4-7   value 长度，big-endian uint32
8-N   UTF-8 value

出站只包一层 cmsg；不要对内层 JSON 再 JSON.stringify，否则服务端会看到带引号的字符串。

清理顺序

  1. 停止音频、视频、屏幕采集。
  2. /session/stop，让服务端关 TurnController 和 MMPG。
  3. leaveRoom() 并销毁 RTC engine。
  4. 页面卸载用 sendBeacon 兜底。

前端排障

  • 无声音：检查麦克风权限、自动播放失败、远端音频订阅。
  • 无欢迎语：检查一次 client.ready、Agent UserId 匹配、3 秒兜底。
  • 无字幕：看 onRoomBinaryMessageReceived 和 subv 解析。
  • 挂断残留：看 /session/stop 与 /health.activeCalls。
