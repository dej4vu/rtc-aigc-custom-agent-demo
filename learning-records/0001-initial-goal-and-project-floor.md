# 用户目标与项目基础

用户明确要从这个仓库掌握 RTC -> ASR -> LLM -> TTS 全流程及其开发方式。仓库已经包含可运行的自有 Agent、真实链路验证和排障文档，因此教学不需要从零实现，而应先建立全链路事件模型，再逐步进入协议、轮次控制和改造技能。

第 1 课只给用户全链路地图和关键事件边界；尚未验证用户能否迁移到代码级开发。下一课应暴露服务端启动协议，但不要一次性展开 LLM、分句和打断实现。

课程主线已覆盖生命周期、服务端启动、轮次状态机、前端消息、TTS 协议和端到端交付。用户在第 2 课展示了异步清理边界的理解；结业能力仍需通过一份改动验收单验证，不能只以浏览课程为准。
