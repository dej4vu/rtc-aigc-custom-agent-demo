Lesson 002

把“一次通话”变成服务端对象

第 1 课给你地图。这一课进入真实开发入口：页面会话、call、RTC Token、MMPG WebSocket 和 session.create 是如何接起来的。

你将获得的小胜利

你能指出浏览器点击“通话”后服务端必须完成哪六件事，也能说出为什么页面 Session 和 call 必须分开设计。

两类会话，不要混淆

Page Session

由 POST /getScenes 创建，代表一个浏览器页面的短暂上下文。前端拿到 SessionID 和场景列表。

作用：避免把场景配置和状态放进浏览器；后续 /session/start 需要它。

Call

由 POST /session/start 创建，代表一次真实通话。服务端生成 roomId、userId、agentUserId、RTC Token、MMPG 连接和 TurnController。

作用：隔离房间身份、音频链路、轮次状态和清理逻辑。

服务端启动调用链

1. 校验请求

读取 SessionID 和 SceneID，确认页面 Session、场景和必要配置都存在。若启动 Promise 已存在，拒绝重复启动。

server/lib/app.js:301

2. 替换旧 call

同一页面再次启动时先停掉旧 call，关闭旧 TurnController 和旧 MMPG。

server/lib/app.js:325

3. 创建身份

每次通话生成独立 demo_room、web_user、agent_user，再为浏览器用户签发一小时 RTC Token。

server/lib/app.js:329

4. 组装自有 Agent

把系统提示词、欢迎语、ArkAgent、TtsClient、MMPG 发送函数和自定义消息函数注入 TurnController。

server/lib/app.js:360

5. 绑定网关事件

MMPG 的普通事件进入 TurnController；网关错误转成 error 事件；网关关闭触发 call 清理。

server/lib/app.js:387

6. 握手与建会话

先 AK/SK 签名建立 WebSocket，再发送 session.create；只有收到 session.created 才把 call 标记为 active。

server/lib/mmpg-client.js:181

session.create 声明了什么

buildMmpgSession() 是协议参数的集中地。它把 Bot 控制台默认值和环境变量合成一份网关配置：

  • AgentConfig.TransmitConfig：使用 RTC 传输，并绑定 AppId、RoomId、Agent UserId 和目标用户。
  • AudioConfig.AudioFormat：用户音频默认 pcm16，助手音频默认 pcm24。
  • AudioConfig.VADConfig：600ms 静音判停、预取和 AI VAD。
  • ASRConfig：Provider 是 volcano；当前网关使用 Mode / ApiKey / ApiResourceId / StreamMode，不包 Credential。
  • SubtitleConfig：关闭平台 RTS 字幕，字幕由你的 Agent 通过 assistant.message 自定义下发。
AgentConfig.TransmitConfig = {
  Type: "rtc",
  AppId, RoomId, UserId,
  UserId: agentUserId,
  TargetUserId: [userId]
};

AudioConfig.AudioFormat = {
  UserAudioFormat: "pcm16",
  AssistantAudioFormat: "pcm24"
};

ASRConfig.ProviderParams = {
  Mode: "bigmodel",
  ApiKey,
  ApiResourceId,
  StreamMode: 0
};

代码源： 官方自有 Agent 接入文档。

前端必须等两个 ready

浏览器收到启动结果后，先保存 RTC 配置和 agentUserId，再进房。它不会立刻上报就绪，而是等：

  1. 麦克风 ready：本地采集和发布准备完成。
  2. Agent ready：收到目标 Agent 的远端音频/用户进入事件。

两者都满足后，前端用 cmsg TLV 发送一次 client.ready。服务端把它转为欢迎语触发条件。这个设计防止欢迎语在浏览器还不能播放时就被消费。

代码源：web/src/lib/RtcClient.ts:148、web/src/lib/RtcClient.ts:509
